# House Price Prediction

A machine learning project that predicts house prices based on different property features such as area, number of bedrooms, bathrooms, parking space, and furnishing status.

The main goal of this project was to understand the complete machine learning workflow starting from raw data preprocessing to model training and prediction.

---

## Features

- Data preprocessing and cleaning
- Handling categorical variables
- Exploratory Data Analysis (EDA)
- Data visualization using Seaborn and Matplotlib
- Linear Regression model training
- Model evaluation using different metrics
- Saving trained model using Pickle

---

## Tech Stack

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
